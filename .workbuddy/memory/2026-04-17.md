## digest.py V3.1 批量推理支持

新增火山方舟批量推理API支持，实现定时任务成本优化：

**核心改动：**
1. 新增 `_call_llm_batch()` 和 `_async_batch_chat()` 函数，支持火山方舟批量推理
2. `_call_llm()` 新增 `batch_mode` 参数，自动路由到批量或实时推理
3. 所有子命令（summarize/run/batch）新增 `--batch-mode` 参数
4. `batch` 子命令默认启用批量模式（适合定时任务场景）
5. 配置系统扩展：支持 `ARK_API_KEY`、`LLM_BATCH_ENDPOINT` 等环境变量
6. `test-api` 子命令显示批量推理配置状态

**配置方式：**
```powershell
$env:ARK_API_KEY = "your-key"
$env:LLM_BATCH_ENDPOINT = "ep-bi-xxxxx"
pip install "volcengine-python-sdk[ark]"
```

**使用示例：**
```bash
python digest.py summarize "AI实践" --batch-mode
python digest.py batch "AI实践" --last-n 7  # 默认批量模式
```

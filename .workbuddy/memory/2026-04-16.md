## wechat-digest 部署 - 重大突破

### 核心成果：微信 4.1.7.59 Win11 解密 + 消息提取全链路打通！

#### 关键发现与解决方案
1. **传统内存扫描方法在微信 4.1.x 上完全失效**
   - wechat-decrypt (Python) 和 wechat-digest 原版 init-keys.py 都是 0/29 匹配
   - 内存中有 158 个 `x'...'` hex pattern 但全部无法通过 HMAC 校验
   - 根因：微信 4.1.7.59 改变了内存密钥存储方式

2. **Wetrace (Hook 方式) 是唯一可行方案**
   - 项目: https://github.com/afumu/wetrace (v0.1.0, 预编译 wetrace.exe)
   - 通过 DLL 注入 Hook setCipherKey 函数，从参数中截获密钥
   - 已验证支持微信 4.1.7.59（研究结论说 4.1.7.57+）
   - 密钥: `49f459a35b3046b39007edcc6c35be772ae49b44a3294c04b0749ad96d311994`
   - API: GET /api/v1/system/wxkey/db 提取密钥, POST /api/v1/system/decrypt 解密

3. **完整部署架构**
   ```
   Wetrace(wetrace.exe) --[API:5200]--> 提取密钥 + 解密26个数据库 --> data/message/*.db(标准SQLite)
       |
       v
   extract_decrypted.py --> 从已解密SQLite提取消息(Markdown格式)
       |
       v
   llm_summarize.py --> LLM多厂商摘要(豆包/GLM/DeepSeek/OpenAI/CLI) --> Markdown报告
   ```
